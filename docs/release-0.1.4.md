# Liberty by Bada 0.1.4

定时关机现在支持真正的每日重复时间表。用户可以添加多个 24 小时制时间，例如 `08:00`、`18:30` 和 `23:00`；保存后，每个时间都会每天执行。列表自动排序和去重，最多保存 24 个时间。

- 关闭 Liberty 或重启 Windows 后，每日计划仍然有效。
- “停用计划”删除 Windows 任务但保留时间，方便重新启用。
- 删除全部时间并保存可彻底清空计划。
- 到点后启动 60 秒 Windows 关机倒计时，不强制关闭有未保存内容的应用。
- 原有一次性倒计时关机继续保留。

实现使用当前用户的 Windows 任务计划程序：一个 Liberty 任务包含多个每日触发器，执行当前 Liberty.exe 的内部参数。电脑需要处于开机、登录且未休眠状态；移动便携版 EXE 后请重新保存计划。

Debug 和 Release 构建、自动回归、双时间实机创建、任务 XML 核对、重启恢复、停用和清空均通过。所有测试任务和时间均已清理，系统没有遗留待执行关机。详见 [testing-0.1.4.md](testing-0.1.4.md)。
